# Reversibility and AI automation

## Prologue

## Introduction

An AI agent is a program that can make decisions on your behalf. For example, some AI agents can send emails and organize files.

This study aims to understand when people are willing to let an AI agent handle some actions on its own, and when they would rather the AI agent ask for permission first.

It is a series of scenarios, and you'll be asked the same questions for each.

Some scenarios are about an AI agent that can organize your files, and others are about an AI agent that can send messages on your behalf.
**Each scenario presents an action the AI can take, and a different method of reversing that action. For each scenario, please indicate whether you would allow the agent to complete the action, based on the available option to reverse it.**

At the end, there's a place to share your free opinion if you're comfortable.

## Vignettes

### File organization scenario

#### S0: Complete irreversibility

An AI agent can go through your files, figure out which ones you haven't used in a long time and that it determines you won't need again, and then delete them. It will do this periodically, without asking you each time.

Deleting the files is permanent, and you cannot restore them.

#### S1: Partial reversibility

An AI agent can go through your files, figure out which ones you haven't used in a long time and that it determines you won't need again, and then delete them. It will do this periodically, without asking you each time.

You can restore them yourself by opening the recycle bin, selecting the files, and clicking restore, which takes about five minutes, but the names and dates of the files are lost forever.

#### S2: Full human reversibility

An AI agent can go through your files, figure out which ones you haven't used in a long time and that it determines you won't need again, and then delete them. It will do this periodically, without asking you each time.

You can restore them yourself by opening the bin, selecting the files, and clicking restore, which takes about five minutes, and everything comes back exactly as it was.

#### S3: Full agent reversibility

An AI agent can go through your files, figure out which ones you haven't used in a long time and that it determines you won't need again, and then delete them. It will do this periodically, without asking you each time.

If you want any of them back, you ask the agent once and it restores everything exactly as it was. The agent is reliable in restoring the files.

### Messaging scenario

#### S0: Complete irreversibility

An AI agent has access to your messaging app, and can send a message to your clients to update them whenever your scheduled meeting time changes. It will do this automatically, without asking you first.

This message cannot be deleted after it's sent.

#### S1: Partial reversibility

An AI agent has access to your messaging app, and can send a message to your clients to update them whenever your scheduled meeting time changes. It will do this automatically, without asking you first.

The app allows you to delete the message yourself. If you delete the message, the app will still show an empty message to the client, meaning they will know you sent something but not the contents of what you sent.

#### S2: Full human reversibility

An AI agent has access to your messaging app, and can send a message to your clients to update them whenever your scheduled meeting time changes. It will do this automatically, without asking you first.

If a message is wrong, you can delete it yourself for everyone in a few taps, which takes about a minute. The message disappears completely.

#### S3: Full agent reversibility

An AI agent has access to your messaging app, and can send a message to your clients to update them whenever your scheduled meeting time changes. It will do this automatically, without asking you first.

If a message is wrong, you ask the agent once and it deletes the message for everyone. The agent is reliable in deleting this message. The message disappears completely.

### Questions for each vignette

How willing would you be to let the AI agent do this action without asking you first?
(1-7 Likert scale, from "not willing at all" to "completely willing").

How risky does letting the agent do this feel?
(1-7 Likert scale, from "not risky at all" to "extremely risky").

How much would the possibility of something going wrong bother you?
(1-7 Likert scale, from "not at all" to "extremely").

If the agent got this wrong, how easily could the outcome be reversed?
(1-7 Likert scale, from "impossible" to "very easily").
